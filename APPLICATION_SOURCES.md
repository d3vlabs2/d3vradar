## Application rules

Greenhouse and Ashby employer forms are checked per job. Eighteen sampled Greenhouse employer forms passed the embedding check. The sampled Ashby employer forms returned X-Frame-Options DENY and stayed external. This is a sample check, not a claim that all jobs on a provider can be embedded. Employer/browser settings may change.

Use Check application options, then Load application when offered. Complete the employer form yourself; your saved documents/profile are not transmitted automatically. After submitting, click I submitted this application, review the date, then Save application. Opening a form never creates an applied record. External fallback remains visible.

Lever supports public listing reads, but its documented submission API requires an employer-issued key and provides no iframe application view. Other unverified sites remain external; no private endpoint, login bypass, CAPTCHA bypass or universal auto-submit is implemented. Remotive, Himalayas, WWR and Remote OK retain their source-attributed listing routes.

Provider documentation: [Greenhouse embeds](https://support.greenhouse.io/hc/en-us/articles/200721644-Choose-a-careers-page-integration-option), [Ashby embeds](https://docs.ashbyhq.com/embedding-ashby-job-boards-in-an-external-careers-page), [Lever postings API](https://github.com/lever/postings-api), [WWR RSS](https://weworkremotely.com/remote-job-rss-feed), [Remote OK API](https://remoteok.com/api).

## Coverage limits

Feeds supply the provider snapshot/page available through that endpoint. Indexed search is limited to 20 results per source and depends on your optional paid API allowance; no live paid Brave key was used in build verification. The dashboard currently loads up to 3,000 recently discovered listings; saved application records remain persisted. This source expansion does not guarantee exhaustive search of every employer or all historical listings.
